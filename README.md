# Baserow for LazyCat

上游：https://github.com/baserow/baserow

包名：community.lazycat.app.baserow（default 前缀）

使用 mirror 模式和稳定镜像 SemVer，linux/amd64，仅喵喵商店。

首次使用请按官方注册流程创建账号。保留 Baserow 自身登录鉴权。数据库和运行数据保存在应用内部持久目录。

按要求开放 public_path /，请保持上游认证。文件操作已接懒猫选择器。图标来自上游 GitHub 组织头像。

组织 Secrets：APPSTORE_URL、APPSTORE_TOKEN，以及可选 PRIVATE_STORE_GROUP_CODES。
